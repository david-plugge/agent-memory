# Svelte / Tailwind conventions

- **Svelte 5 runes** (`$state`, `$derived`, `$props`, `$effect`) — never `export let` or the
  legacy store-in-component patterns.
- **Styling is token utilities only.** Design tokens live in `src/routes/layout.css` (the CSS
  entry configured in `components.json`) and map into Tailwind v4 `@theme inline`. Use the
  semantic shadcn tokens: `bg-background`, `text-foreground`, `text-muted-foreground`,
  `border-border`, `bg-primary`/`text-primary-foreground`, `bg-card`, plus the project brand
  tokens `bg-sunny`/`text-sunny-foreground` and `bg-coral`/`text-coral-foreground`. Prefer these
  over Tailwind's default color palette. Radii use the `--radius`-derived scale (`rounded-lg`,
  `rounded-2xl`, `rounded-3xl`).
- **Dark mode** is class-based (`.dark`, via `@custom-variant dark`). Both light and `.dark`
  token values are defined in `layout.css`; the generated shadcn components carry their own
  `dark:` variants. There is no theme toggle wired up yet, so the app renders light by default.
- **Mobile-first.** Author base styles for the smallest viewport and layer wider layouts with
  `sm:`/`md:`/`lg:`. Touch targets ≥44px; primary actions within thumb reach; respect safe areas
  (`env(safe-area-inset-*)`). See the project `CLAUDE.md` for the full mobile-first checklist.
- `src/lib/components/ui/**` is generated by the **shadcn-svelte** CLI — add or regenerate
  components via the CLI, don't hand-edit them. App-specific components live in
  `src/lib/components/*.svelte`.
